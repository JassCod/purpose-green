# Purpose Green — 3D landing page

A sustainability landing page with an interactive three.js scene: a floating eco-island with an eco house, wind turbines, a solar farm, a pond, trees, clouds and drifting pollen.

- Drag to orbit the island; the scene also follows the pointer.
- Static files only. three.js is vendored in `vendor/`, so there's no build step.
- Works on GitHub Pages: Settings → Pages → Deploy from branch `main` / root.

Run locally:

```bash
python3 -m http.server 8000
```
